dollar_one_recognizer_py documentation
=======================================

A Python 3 implementation of the **$1 Unistroke Recognizer** (Wobbrock, Wilson,
and Li, UIST '07), a lightweight single-stroke gesture recognition algorithm
that needs no machine-learning training.

See the `project README <https://github.com/yuzujelly2222/dollar_one_recognizer_python>`_
for installation and usage examples.
